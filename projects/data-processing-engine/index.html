Implemented a suite of production-grade Python utility programs focusing on resilient file I/O, streaming text log processing, structured JSON error categorization, and tabular CSV analytical reporting.

Overview & Philosophy

Reliable systems engineering begins with mastering core fundamentals: how data moves between transient memory and persistent storage, how errors propagate, and how software behaves when input files are incomplete, corrupted, or absent.

This suite of academic and systems programming projects was constructed to test and solidify practical competency in Python 3, emphasizing defensive exception recovery, optimal loop control, and clean modular code organization.

Implemented Systems & Technical Breakdown

1. Student Record Management System (`students.txt`)

A persistent, menu-driven CLI utility enabling users to add, query, update, and display student academic profiles (Roll Number, Name, Course Marks). Key architectural facets include:

  • Safe file opening modes (a+, r) with context managers to guarantee immediate file handle release.
  • Delimited serialization and deserialization routines with data sanitization preventing newline injection.
  • Input validation loops that trap format anomalies before committing entries to disk.

2. Resilient Log File Reader (`log.txt`)

An enterprise-inspired log monitoring utility engineered to parse system event streams line-by-line without consuming excessive memory on large files:

  • Employs generator-based line streaming to ensure predictable O(1) memory overhead.
  • Detects and tallies critical error severity markers (such as [ERROR] and [CRITICAL]).
  • Robustly recovers from missing-file conditions using explicit try...except FileNotFoundError blocks.

3. JSON-Based Log Analyzer (`logs.json`)

Structured logging is the backbone of modern cloud microservices. This utility consumes JSON array logs containing timestamps, service names, and message payloads:

  • Parses and aggregates occurrences of INFO, WARNING, and ERROR entries.
  • Employs resilient handling for json.JSONDecodeError, flagging truncated or malformed records without halting execution.
  • Outputs clean summary statistics highlighting system health ratios.

4. CSV-Based Log Processing & Summarization

An analytical script utilizing Python's built-in csv reader and dictionary mapping to process tabular execution summaries, filter anomalous rows, and export clean aggregated metrics for reporting dashboards.

Key Engineering Takeaways

Building these programs honed an instinct for defensive programming: never trusting raw external input, writing graceful error traps, and ensuring that software fails predictably and safely rather than abruptly crashing in production.
