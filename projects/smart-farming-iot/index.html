Built and debugged an IoT hardware prototype using the ESP32 microcontroller to capture live environmental metrics—such as soil moisture, ambient humidity, and temperature—bridging physical field telemetry directly with web platforms.

Project Overview

Effective precision agriculture requires ground truth data: direct, real-time measurements from the soil and field conditions rather than regional estimates. This project represents a hands-on exploration of embedded systems and IoT hardware to construct a field monitoring sensor node capable of capturing telemetry and transmitting metrics to upstream dashboards.

Hardware Selection: ESP32 vs. ESP8266

A key architectural deliberation in this project was selecting the primary microcontroller platform. While the ESP8266 was evaluated as an ultra-low-cost alternative, the ESP32 was selected due to:

  • Dual-Core Tensilica Xtensa 32-bit LX6: Allowing dedicated core separation between sensor polling routines and network communication tasks.
  • Multi-Channel 12-bit ADCs: Enabling simultaneous connection of multiple analog soil sensors without requiring external multiplexers.
  • Integrated Wi-Fi & Bluetooth LE: Enabling both remote telemetry publishing and local device pairing for field technicians.
  • Deep Sleep Power Modes: Essential for battery and solar-powered deployments in remote agricultural fields.

Development Workflow & Firmware Uploading

Using the Arduino IDE and embedded C/C++, the development process involved configuring the ESP32 board support package, mapping GPIO pins for analog capacitive soil moisture sensors, and establishing robust baud-rate serial communication (115200 bps) for real-time telemetry streaming and debugging.

Hardware Troubleshooting & Debugging Insights

Hardware prototyping always brings unique physical and electrical hurdles. Key technical issues diagnosed and resolved during this project included:

  • COM Port Detection & USB Drivers: Diagnosing host PC device detection failures by resolving USB-to-UART bridge driver issues (CP2102 vs. CH340 chipsets) and managing bootloader mode triggers (Boot button + EN pin sequence).
  • ADC Linearity & Voltage Spikes: Compensating for the non-linear response of the ESP32 analog-to-digital converter near 0V and 3.3V thresholds using algorithmic mapping and multi-sample smoothing.
  • Sensor Corrosion Prevention: Evaluating capacitive moisture sensing techniques over resistive probes to eliminate direct electrolytic degradation caused by continuous DC currents in damp soil.

Next Steps in Hardware Integration

Ongoing work focuses on integrating MQTT/HTTP telemetry transmission to dispatch field sensor payloads directly into the Smart Agriculture Web Platform backend, forming a closed-loop automated irrigation advisory system.
